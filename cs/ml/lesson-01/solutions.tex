\begin{solution}{ex:ml-1}
  Let's compute $Z=XW+\mathbf{1}_4 \mathbf{b}^{\!\top}$:
  \[
    \begin{gathered}
      X = \begin{pmatrix}1&0&2\\0&3&1\\-1&1&1\\2&1&0\end{pmatrix},\quad
      W = \begin{pmatrix}1&-1\\0&2\\1&1\end{pmatrix}\\
      XW = \begin{pmatrix}3&1\\1&7\\0&4\\2&0\end{pmatrix}\\
      \mathbf{1}_4 \mathbf{b}^{\!\top} = \begin{pmatrix}0.5&-0.5\\0.5&-0.5\\0.5&-0.5\\0.5&-0.5\end{pmatrix}\\
      XW + \mathbf{1}_4 \mathbf{b}^{\!\top} = \begin{pmatrix}3.5&0.5\\1.5&6.5\\0.5&3.5\\1.5&-0.5\end{pmatrix}\\
      Z = \begin{pmatrix}3.5&0.5\\1.5&6.5\\0.5&3.5\\1.5&-0.5\end{pmatrix}\\
      R=\operatorname{relu}(Z)=\begin{pmatrix}3.5&0.5\\1.5&6.5\\0.5&3.5\\1.5&0\end{pmatrix}\\
    \end{gathered}
  \]
  Let's check that the first row of Z equals $\mathbf{x}^{\!\top}_1W+\mathbf{b}^{\!\top}$:
  \[
    \begin{gathered}
      \mathbf{x}^{\!\top}_1=\begin{pmatrix}1&0&2\end{pmatrix}\\
      W = \begin{pmatrix}1&-1\\0&2\\1&1\end{pmatrix}\\
      \mathbf{x}^{\!\top}_1W=\begin{pmatrix}3&1\end{pmatrix}
      \mathbf{b}^{\!\top} = \begin{pmatrix}0.5&-0.5\end{pmatrix}
      \mathbf{x}^{\!\top}_1W+\mathbf{b}^{\!\top}=\begin{pmatrix}3.5&0.5\end{pmatrix}
    \end{gathered}
  \]
  We can see that it is equal to the first row of Z.\\
  (b)
  The shape of Z and R are both $R^{m\times2}$, and $\mathbf{1}_4 \mathbf{b}^{\!\top}$ has the same shape.\\
  (c)
  The number of parameters for this layer is $n\cdot 2+1\cdot 2 = 8$. If $n=784$ and $p=128$, the number of parameters would be $n\cdot p + p = 784\cdot 128 + 128 = 100480$ \\
  (d)
  $R$ has only one entry which is zero, namely the bottom right entry. The map $X \mapsto R$ is not linear in X because of the non-linear activation function. The easiest example of $X$ and $a$ for which $\operatorname{relu}(aX) \ne a\operatorname{relu}(X)$ is $X=\begin{pmatrix}1\end{pmatrix}$ and $a=-1$. The inequality is trivial. The negative entry in $Z$ becomes the zero entry in $R$.
\end{solution}
